# 羊毛数据结构说明

> 供「羊毛付费推送」项目对接使用。羊毛空间抓取的帖子统一整理为以下结构后入库 / 推送。

## 字段定义

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| title | string | 是 | 帖子标题，原文标题，不改写 |
| source | string | 是 | 来源站点，如 LINUX DO / 小众软件 / NodeSeek / V2EX |
| url | string | 是 | 帖子原始链接 |
| published_at | string (ISO 8601) | 是 | 发布时间，如 2026-11-09T15:30:00+08:00 |
| category | string | 是 | 分类：免费白嫖 / 限免 / 低价优惠 / 其他 |
| summary | string | 是 | 一句话摘要：是什么、怎么领、有什么限制 |
| affiliate_url | string | 否 | 返佣链接；无返佣渠道时留空，推送时回退到 url |

## 约定

- 只收录近 7 天内发布的帖子，过期自动清理。
- 抓取失败的来源本轮跳过，沿用上一轮数据，不用空数据覆盖。
- 推送侧只依赖本结构，不直接耦合各来源站点的原始格式。
